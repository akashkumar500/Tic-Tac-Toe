# ⏰ Tic-Tac-Toe  

A **classic Tic-Tac-Toe game** built using **HTML, CSS, and JavaScript**. Play against a friend or the computer in this fun and engaging game!  

## 🔗 Live Demo  
Try the game here:  
- **Pages:** [https://akash-tic-tic.pages.dev/](https://akash-tic-tic.pages.dev/)  
- **Netlify:** [https://akash-tic-tic.netlify.app/](https://akash-tic-tic.netlify.app/)  

## 📌 Features  
✔️ **Two-player local mode** – Play with a friend on the same device.  
✔️ **Player vs Computer mode** – Challenge the computer to a game.  
✔️ Win detection system.  
✔️ Restart button.  
✔️ Simple and user-friendly interface.  

## 🛠️ Technologies Used  
- **HTML** – Game structure  
- **CSS** – Styling and animations  
- **JavaScript** – Game logic, including player vs. computer AI  

## 🚀 How to Play  
1. Open the **[Live Demo](https://akash-tic-tic.pages.dev/)**.  
2. Choose the **game mode** (Player vs Player or Player vs Computer).  
3. **Player X** and **Player O** take turns clicking on a cell in **two-player mode**.  
   - In **Player vs Computer mode**, you’ll play against the AI.  
4. The first player to get **three in a row (horizontal, vertical, or diagonal)** wins!  
5. Click **Restart** to play again.
